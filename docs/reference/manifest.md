# Chart manifest

`charts/<name>/manifest.yaml` is the reviewed intent for one mirrored chart, and the only file in a chart directory that
you normally edit by hand. Everything derived from it is regenerated by `make update`. The schema is
`mirror.patchy.bitwisemedia.uk/v1alpha1`, `kind: Chart`, and unknown fields are rejected.

## Top level

| Field        | Required | Meaning                                                                  |
| ------------ | -------- | ------------------------------------------------------------------------ |
| `apiVersion` | yes      | `mirror.patchy.bitwisemedia.uk/v1alpha1`                                 |
| `kind`       | yes      | `Chart`                                                                  |
| `name`       | yes      | must match the directory name                                            |
| `chart`      | yes      | the upstream pin (below)                                                 |
| `discovery`  |          | how the render for image discovery runs                                  |
| `images`     |          | tracking, extras, excludes and per-image provenance                      |
| `ociRefs`    |          | non-mirror `oci://` references allowed to survive in the rendered output |
| `scan`       |          | per-chart overrides of the global scan policy                            |
| `publish`    |          | where the chart is pushed                                                |

## `chart`

| Field               | Meaning                                                                                            |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| `repo`              | upstream location: an `oci://` registry path or an `https://` helm repository (`index.yaml`)       |
| `name`              | the upstream chart name                                                                            |
| `version`           | the pinned version, written by `make update`; use upstream's spelling (keep a leading `v`)         |
| `versionConstraint` | the semver range `update` may move within (default: none)                                          |
| `lockstep`          | update-group name shared with sibling entries that must bump together                              |
| `verifyUpstream`    | provenance of the chart archive (a [verify rule](#verify-rules)); `provider: none` documents a gap |

## `discovery`

| Field         | Default        | Meaning                                       |
| ------------- | -------------- | --------------------------------------------- |
| `namespace`   | the entry name | namespace to render into                      |
| `valuesFiles` | —              | values files, relative to the entry directory |
| `kubeVersion` | `1.34.0`       | Kubernetes version to render for              |
| `apiVersions` | —              | extra `.Capabilities.APIVersions` entries     |

## `images`

| Field                       | Meaning                                                                                                                                        |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `track[]`                   | images released on their own schedule. See [Tracked images](../concepts/tracked-images.md)                                                     |
| `track[].image`             | the image repository to pick tags for                                                                                                          |
| `track[].versionConstraint` | bound for the pick; default: the pinned tag's own major (`>=<pin> <<major+1>.0.0`)                                                             |
| `track[].cooldownDays`      | override `mirror.yaml` `update.cooldownDays`; `0` tracks head                                                                                  |
| `track[].valuesFile`        | default: the first `discovery.valuesFiles` entry                                                                                               |
| `track[].valuesPath`        | yq-style path to the image reference or bare tag that the pick replaces                                                                        |
| `distributionManifests`     | derive extra images from an operator's manifests artifact into `images.extra.yaml` (`artifact`, `components[]`, `registry`, default `ghcr.io`) |
| `extra[]`                   | images helm rendering can't see: `image` (`{appVersion}` expands) and `reason`                                                                 |
| `exclude[]`                 | `pattern` globs dropping discovered references                                                                                                 |
| `allowEmpty`                | accept a chart that renders no images (CRD-only charts)                                                                                        |
| `verifyUpstream[]`          | first-match-wins rules over canonical source references: `match` glob plus a [verify rule](#verify-rules). Every locked image must match one   |

## Verify rules

| Field                       | Meaning                                                                          |
| --------------------------- | -------------------------------------------------------------------------------- |
| `provider`                  | `cosign-keyless`, `cosign-key` or `none` (default `none`: a documented gap)      |
| `certificateIdentityRegexp` | required for `cosign-keyless`: regex over the signing certificate's identity     |
| `certificateOidcIssuer`     | default `https://token.actions.githubusercontent.com`                            |
| `key`                       | required for `cosign-key`: URL or path of the public key                         |
| `signatureDigestAlgorithm`  | payload digest for key publishers signing with a non-default one (e.g. `sha512`) |
| `signatureRepository`       | where signatures live, when the publisher keeps them apart from the artifact     |

## `ociRefs`, `scan`, `publish`

| Field                     | Meaning                                                                                                                                   |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `ociRefs.allow[]`         | `pattern` and `reason` for one `oci://` reference allowed outside the mirror                                                              |
| `scan.failOn`             | severities that block (overrides `mirror.yaml`)                                                                                           |
| `scan.ignoreUnfixed`      | don't block findings with no upstream fix (overrides `mirror.yaml`)                                                                       |
| `scan.allowlist.generate` | rebuild `security/allowlist.yaml` from the scan during `update`. See [Generated allowlists](../concepts/scanning.md#generated-allowlists) |
| `scan.allowlist.preamble` | whole-file context, rendered as comments at the top of the generated allowlist                                                            |
| `publish.chartRepo`       | repository path under every registry URL (default `<chartNamespace>/<name>`)                                                              |

## A complete example

[gha-runner-scale-set](../charts/gha-runner-scale-set.md) uses most of the fields at once, including lockstep, a tracked
image with a constraint, keyless image provenance with an unsigned chart, and a generated allowlist with a preamble:

```yaml
--8<-- "charts/gha-runner-scale-set/manifest.yaml"
```
